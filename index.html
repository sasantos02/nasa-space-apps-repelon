Repelón Risk Lens – rotation scenario explorer

Screening tool for NASA Space Apps 2026 (Field Shift). Rule-based, no machine learning, not a forecast and not a recommendation. Rainfall: NASA GPM IMERG V07; vegetation: Sentinel-2 (ESA). Thresholds, weights and every scenario setting below are uncalibrated assumptions to be reviewed locally.

1. Map: click a parcel

How to use: ① click a parcel on the map (or type its code) → ② move the rainfall bar → ③ edit the monthly calendars → ④ set the farmer’s priorities.

Low ● Moderate ● High ● · dot size ~ area · black ring = selected. Most High dots are tiny bare-soil lots, not crops.

2. Rainfall what-if (not a forecast)

Vulnerability stays fixed; hazard = 1 − rain/normal; risk = 0.5·hazard + 0.5·vulnerability. The same factor scales the monthly rain below (assumption). A month is “dry” if scaled rain < 50 mm (assumption).

3. Scenario calendars (editable assumptions)

Source for sowing at the start of the rains: Contexto Ganadero; reserve forage example: AGROSAVIA (see repository). Crop windows are assumptions. Monthly rain: GPM IMERG 2021–2025 mean.

4. Farmer priorities → scenario reading

Scores are simple shares computed from the calendars (e.g., water-needing months that are not dry). Plans without a crop score 0 on “sowing with rains”. This is a transparent reading of assumptions, not a yield or income model; soil health is reduced to months with cover.

Limits: no parcel-level crop data; High class mostly tiny bare-soil lots (not crops); ranking is robust to ±20 % changes, class counts are not; farmer-priority weights are adjustable assumptions. Full text in the repository (README, LIMITACIONES.md, ROTATION_SCENARIOS_EN.md).
